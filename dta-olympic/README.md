# DTA pathway proposal — Olympic College (planning stub)

**Status: SKETCH (2026-06-02).** Plan only — not executed.

## Goal

Produce a **proposal for a Direct Transfer Associate (DTA) degree pathway** that
**Kelsey** can use in a meeting with **Olympic College (OC)** representatives.

The proposal connects three inputs:

1. **PSD's current dual-credit offerings** (Running Start, College in the High
   School, CTE Dual Credit, AP/IB) — *to be gathered from PSD; not in this repo.*
2. **Olympic College's catalog** — *already available in this repo*
   (`../catalogs/olympic-courses-classified.json`, 1,246 courses, 174 WA Common
   Course Numbers). DTA anchor courses confirmed present (ENGL&101/102, CMST&220,
   MATH&107/141/146, lab sciences).
3. **OC's DTA degree requirements** — ICRC-based distribution structure;
   OC-specific worksheet *to be confirmed from OC's catalog/advising sheet.*

**Output:** a discussion document (model pathway + coverage/gap crosswalk + asks
for OC) for Kelsey's meeting.

## Files

- `PLAN.md` — inputs, the mapping approach, work steps, draft proposal outline, open questions.

## Note

The existing equivalency tool classifies OC courses into **HS credit types**, which
are *not* the same as **DTA distribution areas** (Communication Skills,
Quantitative/Symbolic Reasoning, Humanities, Social Sciences, Natural Sciences).
A DTA-area mapping layer is the new piece — but the WA Common Course Number
backbone (174 OC CCNs) makes much of it reusable. See `PLAN.md`.
